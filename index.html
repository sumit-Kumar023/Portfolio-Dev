Atlas Enterprise AI: Enterprise Knowledge Assistant

  • Full-stack enterprise RAG assistant answering questions over uploaded documents. FastAPI backend with a LangGraph workflow coordinating retrieval, generation, guardrail checks, and PostgreSQL-backed conversation memory for follow-ups.
  • Browser uploads go straight to private S3 via presigned URLs. Documents are chunked, embedded with Bedrock Titan Text Embeddings V2, and indexed in Pinecone. Answers are generated by Bedrock Nova Lite with source citations.
  • Deterministic input/output guardrails, human-in-the-loop approval queue, audit and feedback logging, and optional GlassFlow Rius tracing for observability.
  • Automated delivery: GitHub Actions authenticates to AWS via OIDC, builds a commit-tagged Docker image, pushes it to ECR, and deploys to EC2 through a self-hosted runner.
